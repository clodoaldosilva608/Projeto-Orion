# Capítulo 1 — Bem-vindo ao Orion

Parabéns! Você está começando a usar o Orion, a plataforma que vai transformar a forma como você acompanha suas metas e resultados comerciais. Este manual foi escrito para ajudá-lo a tirar o máximo proveito do sistema, desde o primeiro acesso até funcionalidades avançadas.

O Orion substitui as antigas fichas de papel e planilhas por um sistema moderno que calcula tudo automaticamente, mostra seu progresso em tempo real e ainda permite que você veja como está se saindo em relação aos colegas de equipe.

## 1.1 O que o Orion faz por você

- **Mostra suas metas do dia** em uma tela simples e clara
- **Calcula seu progresso automaticamente** conforme você lança resultados
- **Mostra o ranking da equipe** em tempo real
- **Notifica sobre campanhas** e oportunidades de premiação
- **Guarda seu histórico** para você ver sua evolução ao longo do tempo
- **Funciona no celular** — pode instalar como aplicativo
- **Funciona offline** — lança resultados mesmo sem internet
- **Tem IA Coach** — sugere melhorias baseadas no seu desempenho real
- **Envia notificações push** — você fica sabendo das novidades no celular
- **Permite exportar** seus relatórios em PDF e Excel

## 1.2 Requisitos para uso

- Computador, tablet ou celular com acesso à internet
- Navegador moderno (Chrome, Edge, Safari, Firefox) atualizado nos últimos 12 meses
- Conta de usuário criada pelo seu gerente ou administrador
- E-mail ou matrícula + senha fornecidos pela empresa
- Permissões de notificação habilitadas no navegador (opcional, mas recomendado)
- Pelo menos 50 MB de espaço livre no dispositivo (para uso offline)

## 1.3 Navegadores suportados

| Navegador | Versão mínima | Observação |
|-----------|---------------|------------|
| Google Chrome | 110+ | Recomendado |
| Microsoft Edge | 110+ | Excelente compatibilidade |
| Mozilla Firefox | 110+ | Suporte completo |
| Apple Safari | 16+ | macOS e iOS |
| Opera | 100+ | Suporte completo |
| Samsung Internet | 22+ | Android |
| Brave | 1.50+ | Suporte completo |

> **Aviso:** Internet Explorer 11 não é suportado. Navegadores desatualizados podem apresentar falhas visuais ou de funcionamento.

## 1.4 Para quem é este manual

Este manual é destinado a:

- **Vendedores** que usam o Orion para lançar resultados e acompanhar metas
- **Supervisores** que acompanham a equipe e aprovam resultados
- **Caixas e auxiliares** que registram atendimentos
- **Qualquer usuário final** que precise entender o funcionamento básico do sistema

Se você é gerente, administrador da empresa ou responsável técnico, consulte o **Documento 20 — Manual do Administrador**.

# Capítulo 2 — Primeiro Acesso

## 2.1 Como entrar no sistema

1. Acesse o endereço fornecido pela sua empresa (ex: `app.suaempresa.com`)
2. Você verá a tela de login:

```
┌────────────────────────────────────────┐
│              [ LOGO ]                  │
│                                        │
│        Bem-vindo ao Orion              │
│                                        │
│   ┌──────────────────────────────────┐ │
│   │  E-mail, matrícula ou CPF        │ │
│   └──────────────────────────────────┘ │
│   ┌──────────────────────────────────┐ │
│   │  Senha                           │ │
│   └──────────────────────────────────┘ │
│                                        │
│   [  Entrar  ]   Esqueci minha senha   │
│                                        │
│   □ Manter conectado                   │
└────────────────────────────────────────┘
```

3. Digite seu e-mail, matrícula ou CPF (conforme configurado pela empresa)
4. Digite sua senha
5. Clique em **Entrar**

## 2.2 Esqueci minha senha

Se você esqueceu sua senha:

1. Na tela de login, clique em **Esqueci minha senha**
2. Informe seu e-mail ou matrícula
3. Você receberá um e-mail com um link de recuperação (válido por 1 hora)
4. Clique no link
5. Cadastre sua nova senha (mínimo 8 caracteres, com letra maiúscula, número e caractere especial)

> **Dica:** Verifique a pasta de spam/lixo eletrônico se não receber o e-mail em 5 minutos.

## 2.3 Primeira senha temporária

Se o administrador criou sua conta com senha temporária:

1. Faça login com a senha temporária
2. O sistema pedirá para você criar uma nova senha imediatamente:

```
┌────────────────────────────────────────┐
│   ⚠️  Troca de senha obrigatória        │
│                                        │
│   Por segurança, você deve definir     │
│   uma nova senha antes de continuar.   │
│                                        │
│   Senha atual:     [____________]      │
│   Nova senha:      [____________]      │
│   Confirmar:       [____________]      │
│                                        │
│   □ Força da senha: ████████░░ Forte   │
│                                        │
│   [ Cancelar ]   [ Salvar nova senha ] │
└────────────────────────────────────────┘
```

3. Escolha uma senha forte que você lembre
4. A partir de agora, use essa nova senha

## 2.4 Ativando o 2FA (autenticação em dois fatores)

Se sua empresa exigir (ou se você quiser mais segurança):

1. Após o primeiro login, acesse **Perfil > Segurança > Autenticação em 2 fatores**
2. Clique em **Ativar**
3. Escaneie o QR code com Google Authenticator, Microsoft Authenticator ou Authy
4. Digite o código de 6 dígitos exibido no app
5. Salve os **códigos de backup** em local seguro (são 10 códigos únicos para uso emergencial)

## 2.5 Termos de uso e consentimento LGPD

No primeiro acesso você deverá:

1. Ler os Termos de Uso
2. Ler a Política de Privacidade
3. Marcar a caixa de consentimento: *"Concordo com o tratamento dos meus dados conforme a Política de Privacidade"*
4. Opcionalmente, autorizar o uso de dados para insights de IA (pode ser revogado depois)

> **Importante:** Sem o consentimento LGPD, você não consegue usar o sistema. Você pode revogar o consentimento a qualquer momento em **Perfil > Privacidade**, mas isso implica em bloqueio de acesso.

## 3.2 Cards de Indicadores

No topo, você vê cards com seus indicadores do dia. Cada card mostra:

- **Nome do indicador** (ex: Faturamento, Clientes, Ticket Médio)
- **Seu resultado atual**
- **Meta do dia**
- **Percentual atingido**
- **Cor de status:**
  - 🟢 Verde — 80% ou mais da meta
  - 🟡 Amarelo — entre 50% e 79%
  - 🔴 Vermelho — menos de 50%

Passe o mouse sobre um card para ver:

- Tendência (comparado a ontem)
- Média dos últimos 7 dias
- Projeção de fechamento do dia

## 3.3 Gráfico de Evolução

Mostra como seu faturamento evoluiu ao longo do dia. Atualiza automaticamente a cada 15 minutos.

Clique no gráfico para alternar entre:

- **Hoje** (padrão) — valores por hora
- **7 dias** — valores diários
- **30 dias** — valores diários com média móvel
- **Mês atual** — valores semanais

## 3.4 Ranking do Dia

Mostra os 5 melhores vendedores da equipe no dia e sua posição atual.

Clique em **Ver ranking completo** para acessar o ranking completo (Capítulo 6).

## 3.5 Próximas Ações

Alertas inteligentes:

- "Campanha X termina em 3 dias"

- "Aprovamos seu resultado de ontem ✓"
- "Você subiu 2 posições no ranking! 🎉"

Clique em qualquer ação para ser levado direto à tela correspondente.

## 3.6 Personalizando o Dashboard

Você pode personalizar seu dashboard:

1. Clique no ícone de engrenagem no canto superior direito
2. Selecione **Editar Dashboard**
3. Arraste os cards para reordenar
4. Clique no **X** para remover cards que não quer ver
5. Clique em **+ Adicionar widget** para incluir novos
6. Clique em **Salvar Layout**

Seus widgets disponíveis dependem das permissões do seu cargo.

# Capítulo 4 — Lançando Resultados

Esta é a tarefa mais importante que você fará no Orion: registrar seus resultados diários.

```
│  │ R$ [_____________]                                          │  │

│                                                                  │

```

3. Para cada indicador, digite o valor do dia
4. A barra de progresso atualiza em tempo real conforme você digita
5. Opcionalmente, escreva uma observação
6. Clique em **Salvar Resultado**

## 4.2 Indicadores que você vê

Apenas os indicadores que o seu gerente atribuiu a você aparecem na tela. Se achar que falta algum, converse com seu supervisor.

Você pode ver quais indicadores são:

- **Diários:** devem ser preenchidos todos os dias
- **Semanais:** preenchidos uma vez por semana (geralmente sexta-feira)
- **Mensais:** preenchidos no fim do mês
- **Por evento:** preenchidos quando um evento específico acontece

## 4.3 Anexando comprovante

Se quiser anexar uma foto do comprovante de venda:

1. Clique em **Anexar comprovante**
2. Selecione a foto do seu dispositivo
3. A foto será enviada junto com o resultado

Formatos aceitos: JPG, PNG, PDF
Tamanho máximo: 5 MB por arquivo
Máximo de arquivos por resultado: 5

## 4.4 Gravando áudio (observação por voz)

Em vez de digitar a observação, você pode gravar um áudio:

1. Clique no ícone de microfone 🎤
2. Fale sua observação (até 2 minutos)
3. Clique novamente para parar
4. O áudio fica anexado ao resultado
5. Você pode ouvir antes de salvar clicando em ▶️

> **Dica:** Use áudios para explicar situações especiais (cliente devolveu produto, venda parcelada, etc.).

## 4.5 Resultado acima do esperado

Se você lançar um valor muito acima do normal (mais de 200% da meta), o sistema pedirá uma justificativa. Isso é para evitar erros de digitação e garantir que os dados estejam corretos.

Exemplo: se sua meta de faturamento é R$ 3.000 e você lançar R$ 9.000, aparecerá:

```
┌────────────────────────────────────────────────────────────────┐
│  ⚠️  Valor acima do esperado                                    │
│                                                                │
│  O valor informado (R$ 9.000,00) é 300% da meta diária.        │
│                                                                │
│  Isso pode estar correto, mas queremos confirmar para evitar   │
│  erros de digitação.                                           │
│                                                                │
│  Por favor, justifique:                                        │
│  ┌──────────────────────────────────────────────────────────┐  │
│  │ Venda corporativa para cliente X (R$ 7.500 em perfumes)  │  │
│  └──────────────────────────────────────────────────────────┘  │
│                                                                │
│  [ Revisar valor ]          [ Confirmar e salvar ]             │
└────────────────────────────────────────────────────────────────┘
```

## 4.6 Resultado precisa de aprovação

Alguns indicadores podem exigir aprovação do seu gerente. Nesse caso:

1. Você lança o resultado normalmente
2. Ele fica com status "Pendente de aprovação" (ícone amarelo ⏳)
3. Seu gerente recebe uma notificação
4. Quando ele aprovar, o resultado entra oficialmente no ranking (ícone verde ✓)
5. Se ele rejeitar, você será notificado com a justificativa (ícone vermelho ✗)

## 4.7 Editando resultado ainda não aprovado

Se você lançou errado e o resultado ainda não foi aprovado:

1. Vá em **Histórico > Resultados Recentes**
2. Encontre o resultado
3. Clique em **Editar**
4. Altere o valor
5. Clique em **Salvar**

Se já foi aprovado, você precisará pedir ao seu supervisor para rejeitar e lançar novamente.

## 4.8 Lançando resultado de dia anterior

Esqueceu de lançar ontem? Você pode fazer isso:

1. No formulário de lançamento, clique em **Alterar data**
2. Selecione a data anterior
3. Preencha os valores
4. Salve

> **Importante:** O sistema permite lançar resultados de até 7 dias anteriores. Para períodos maiores, é necessário solicitar ao supervisor (que pode fazer com justificativa).

## 4.9 Confirmação de salvamento

Após salvar, você verá uma confirmação:

## 5.2 Quanto falta para bater a meta

Para cada meta, o Orion mostra:

- **Valor atual:** quanto você já fez
- **Meta:** quanto precisa fazer
- **Percentual:** quanto já atingiu
- **Falta:** quanto ainda falta
- **Sugestão inteligente:** "Para bater, venda R$X a mais nos próximos Y clientes"

Exemplo: "Faturamento: R$1.250 de R$3.000 (42%). Faltam R$1.750."

## 5.3 Histórico de metas

Clique em **Histórico** para ver suas metas dos meses anteriores. Isso ajuda a entender sua evolução.

Você verá:
- Meta do mês vs. resultado alcançado
- Percentual de atingimento
- Comparativo com mesmo mês do ano anterior
- Tendência (crescendo, estável, caindo)

## 5.4 Projeção de meta (IA)

A IA do Orion pode projetar se você vai bater a meta do mês:

1. Em **Metas > Mês**, clique em **Ver Projeção**
2. A IA analisa seu ritmo atual
3. Mostra: "Com seu ritmo atual, você atingirá 92% da meta do mês"
4. Sugestões: "Para bater 100%, você precisaria de R$X a mais por dia"

> **Importante:** A projeção é uma estimativa baseada em dados históricos. Não é garantia.

## 5.5 Metas de campanhas

- Nome da campanha

# Capítulo 6 — Ranking

## 6.1 Como funciona o ranking

O ranking mostra a posição de todos os vendedores da sua equipe, filial ou rede, baseado nos resultados lançados.

- Atualiza automaticamente a cada novo resultado lançado
- Mostra posição atual e tendência (subindo 📈, estável ➡️, caindo 📉)
- Considera apenas resultados aprovados

## 6.2 Tipos de ranking

Você pode ver o ranking por período:

- **Diário:** melhores vendedores do dia
- **Semanal:** melhores da semana
- **Mensal:** melhores do mês
- **Por campanha:** melhores em uma campanha específica
- **Anual:** melhores do ano (acumulado)

## 6.3 Filtros disponíveis

Na tela de ranking, você pode filtrar por:

- **Período:** hoje, semana, mês, ano, personalizado
- **Escopo:** minha equipe, minha filial, todas as filiais (se permitido)
- **Indicador:** ver ranking por faturamento, clientes, TKM, etc.
- **Tipo de vendedor:** todos, apenas vendedores, apenas supervisores

# Capítulo 7 — Campanhas

## 7.1 O que são campanhas

Campanhas são competições temporárias criadas pelo seu gerente. Elas têm:

- **Período definido** (ex: 1 a 10 de agosto)
- **Indicador específico** (ex: quem vende mais perfumes)
- **Premiações** (medalhas, troféus, pontos, brinde)
- **Regras especiais** (ex: apenas vendedores com mais de 6 meses)

## 7.2 Como participar

Quando uma campanha começa:

1. Você recebe uma notificação
2. Acesse **Campanhas** no menu
3. Veja os detalhes: período, indicador, prêmio
4. Lance seus resultados normalmente
5. O sistema acompanha automaticamente

Você não precisa fazer nada especial para participar — apenas continue lançando seus resultados.

> **Importante:** Algumas campanhas exigem aceite explícito. Se for o caso, clique em **Participar** na tela da campanha.

## 7.3 Acompanhando sua posição

Na tela de Campanhas, você vê:

- Sua posição atual no ranking da campanha
- Quanto falta para o próximo colocado
- Quantos dias faltam para o fim
- Prêmio que você pode ganhar
- Seu progresso visual (barra de progresso)

## 7.4 Tipos de campanhas

O Orion suporta vários tipos:

- **Ranking puro:** quem vender mais ganha
- **Meta individual:** quem bater a meta concorre ao prêmio
- **Por equipe:** a equipe com maior média ganha
- **Desafio pessoal:** supere seu próprio recorde
- **Crescimento:** quem crescer mais vs. mês anterior
- **Reativar clientes:** quem atender mais clientes inativos

## 7.5 Premiações

Ao final de uma campanha:

- Os vencedores são anunciados
- Premiações são concedidas automaticamente
- Ficam registradas no seu perfil (medalhas, troféus)
- Você recebe notificação

Tipos de premiação:
- 🥇 **Medalha de Ouro** — 1º lugar
- 🥈 **Medalha de Prata** — 2º lugar
- 🥉 **Medalha de Bronze** — 3º lugar
- 🏆 **Troféu** — conquistas especiais
- ⭐ **Pontos** — acumula para trocar por prêmios
- 🎁 **Brindes físicos** — entregues pela empresa
- 💰 **Bônus financeiro** — creditado pela empresa

## 7.6 Campanhas recorrentes

Algumas campanhas acontecem periodicamente:

- **Mensal:** "Vendedor do mês"
- **Semanal:** "Destaque da semana"
- **Sazonal:** "Black Friday", "Dia das Mães", "Natal"
- **Anual:** "Campeão do ano"

Participe sempre que puder — é uma ótima forma de ganhar prêmios e reconhecimento.

## 7.7 Histórico de campanhas

Em **Campanhas > Histórico**, você vê:

- Campanhas que participou
- Sua posição final em cada uma
- Premiações recebidas
- Evolução ao longo do tempo

# Capítulo 11 — Usando no Celular (PWA)

## 11.1 O que é PWA

PWA (Progressive Web App) é uma tecnologia que permite instalar um site como aplicativo no celular, sem precisar baixar da loja de apps. Vantagens:

- Funciona como app nativo (ícone na tela inicial, tela cheia)
- Mais leve que um app tradicional (não ocupa espaço)
- Recebe notificações push
- Funciona offline
- Atualiza automaticamente

## 11.2 Instalando como aplicativo

### Android (Chrome)

1. Acesse o Orion no Chrome
2. Menu (3 pontos) > **Instalar aplicativo**
3. Confirme
4. Aparecerá ícone na tela inicial

### Android (Edge)

1. Acesse o Orion no Edge
2. Menu (3 pontos) > **Adicionar à tela inicial** ou **Instalar**
3. Confirme

### iPhone (Safari)

1. Acesse o Orion no Safari
2. Botão Compartilhar (quadrado com seta para cima)
3. **Adicionar à Tela de Início**
4. Confirme
5. Aparecerá ícone na tela inicial

### iPhone (Chrome) — limitado

O Chrome no iPhone não suporta instalação de PWA. Use o Safari.

### Desktop (Chrome/Edge)

1. Acesse o Orion no navegador
2. Aparecerá um ícone de instalação na barra de endereço
3. Clique nele > **Instalar**
4. O Orion abrirá em janela própria

## 11.3 Funcionamento offline

Se você estiver sem internet:

- O app ainda abre e mostra seus dados mais recentes
- Você pode lançar resultados (ficam salvos no celular)
- Quando voltar a conexão, sincroniza automaticamente
- Você verá um ícone de "offline" no topo

> **Importante:** Em modo offline, você não vê atualizações de ranking ou notificações novas. Esses dados só chegam quando voltar a conexão.

## 11.4 Notificações push

Após instalar como app:

- Você recebe notificações no celular mesmo com app fechado
- Configure em Perfil > Notificações
- No Android: as notificações funcionam em segundo plano
- No iPhone: necessita iOS 16.4+ e o app deve ser "adicionado à Dock"

## 11.5 Permissões do app

Após instalar, o app pode pedir permissões para:

- **Notificações:** para receber avisos
- **Câmera:** para anexar fotos de comprovantes
- **Microfone:** para gravar áudios de observação
- **Armazenamento:** para salvar arquivos offline

Você pode revogar qualquer permissão depois nas configurações do sistema operacional.

## 11.6 Atualizando o app

O Orion PWA se atualiza automaticamente:

- Sempre que você abrir com internet, ele verifica atualizações
- Se houver, baixa em segundo plano
- Na próxima abertura, já estará atualizado

Você não precisa fazer nada. Mas se perceber que algo não está funcionando:

1. Feche o app completamente
2. Abra novamente
3. Se persistir, desinstale e instale de novo (seus dados não se perdem)

# Capítulo 12 — Inteligência Artificial (Coach Pessoal)

## 12.1 O que a IA faz por você

O Orion tem uma IA que pode:

- Analisar seu desempenho e sugerir melhorias
- Prever se você vai bater a meta do mês
- Recomendar ações específicas
- Explicar por que algo aconteceu ("Por que meu TKM caiu?")
- Sugerir campanhas para participar
- Gerar relatórios narrativos

## 12.2 Como usar

1. No menu, acesse **IA Coach** (se disponível)
2. Você verá dois modos:

### Modo Insights automáticos

No topo, a IA mostra insights gerados automaticamente:

- "🎯 Seu ticket médio subiu 12% esta semana. Continue assim!"
- "⚠️ Você está 8% abaixo do ritmo para bater a meta. Foco em conversão!"
- "💡 Você tem potencial para subir 2 posições no ranking se mantiver o ritmo."

### Modo Chat

Faça perguntas como:

- "Como posso melhorar meu ticket médio?"
- "Vou bater a meta este mês?"
- "Quais indicadores devo focar?"
- "Por que meu faturamento caiu ontem?"
- "Qual produto devo focar para campanha de maio?"
- "Compare meu desempenho com a média da equipe"

3. A IA responderá baseada nos seus dados reais

## 12.3 Exemplos de perguntas úteis

### Sobre metas

- "Faltam quantos dias para eu bater a meta de março?"
- "Qual é a probabilidade de eu bater a meta de faturamento?"
- "Como estou comparado ao mesmo período do ano passado?"

### Sobre desempenho

- "Qual meu indicador mais fraco?"
- "Em quais dias da semana eu vendo mais?"
- "Qual horário tenho maior conversão?"

### Sobre melhorias

- "O que posso fazer para aumentar meu ticket médio?"
- "Como melhorar minha conversão de clientes?"
- "Quais produtos devo priorizar?"

### Sobre campanhas

- "Quais campanhas ativas eu tenho mais chance de ganhar?"
- "Quanto preciso vender para alcançar o 1º lugar na campanha X?"
- "Quais campanhas terminam em breve?"

## 12.4 Importante saber

- A IA **nunca toma decisões automáticas** — apenas sugere
- Você decide se aceita ou não as sugestões
- Seus dados pessoais (CPF, e-mail) **não são enviados** à IA
- A IA pode estar errada — use como referência, não como verdade absoluta
- A IA tem um limite mensal de uso (configurado pela empresa)
- Você pode revogar o consentimento de IA a qualquer momento

## 12.5 Aceitando sugestões

Quando a IA sugere uma ação:

```
┌────────────────────────────────────────────────────────────────┐
│  💡 Sugestão da IA                                            │
│                                                                │
│  Com base no seu histórico, você tem maior conversão entre    │
│  14h e 16h. Sugiro concentrar seus esforços de venda nesse   │
│  horário.                                                     │
│                                                                │
│  Confiança: 87%                                               │
│  Base: análise de 90 dias de resultados                       │
│                                                                │
│  [ Recusar ]   [ Ver análise ]   [ Aceitar e definir lembrete]│

```

- **Aceitar:** ação é executada (ex: lembrete é criado)
- **Recusar:** sugestão é descartada
- **Ver análise:** você vê os dados que a IA usou para sugerir

## 12.6 Revogando consentimento de IA

Se não quiser mais usar a IA:

1. Acesse **Perfil > Privacidade > Consentimentos**
2. Desative "Permitir uso de IA em meus dados"
3. A IA para de analisar seus dados
4. Insights automáticos são desativados
5. Histórico de sugestões é apagado

Você pode reativar quando quiser.

# Capítulo 13 — FAQ Expandido

## Acesso e login

### P1: Esqueci minha senha, o que faço?
**R:** Na tela de login, clique em "Esqueci minha senha" e siga as instruções enviadas por e-mail. O link é válido por 1 hora.

### P2: Esqueci meu e-mail de cadastro, como descubro?
**R:** Tente com sua matrícula ou CPF. Se também não lembrar, peça ao seu supervisor ou administrador para confirmar o login cadastrado.

### P3: Estou bloqueado após várias tentativas. O que faço?
**R:** Após 5 tentativas inválidas, a conta é bloqueada por 15 minutos. Aguarde esse tempo e tente novamente. Se tiver urgência, peça ao seu supervisor para desbloquear.

### P4: Como faço login com 2FA se perdi meu celular?
**R:** Use um dos códigos de backup que você salvou ao ativar o 2FA. Se não os tiver, contate o administrador para redefinir o 2FA (será necessário comprovar identidade).

### P5: Posso usar o Orion em mais de um dispositivo?
**R:** Sim! Você pode estar logado em até 3 dispositivos simultaneamente. Em **Perfil > Sessões** você gerencia eles.

### P6: O sistema pede para trocar senha a cada 90 dias. Tem como desativar?
**R:** Não. Essa é uma política de segurança da empresa. Algumas empresas configuram período maior (180 dias) ou menor (30 dias). Fale com o administrador.

## Resultados

### P7: Lançei um resultado errado, como corrijo?
**R:** Se o resultado ainda não foi aprovado, você pode editar em **Histórico > Resultados Recentes > Editar**. Se já foi aprovado, peça ao seu supervisor para rejeitar e lançar novamente.

### P8: Por que meu resultado está pendente de aprovação?
**R:** Alguns indicadores exigem aprovação do supervisor (configurado pelo admin). Seu supervisor foi notificado e vai aprovar em breve.

### P9: Posso lançar resultado de ontem?
**R:** Sim. No formulário de lançamento, clique em **Alterar data** e selecione a data anterior. Você pode lançar resultados de até 7 dias atrás.

### P10: Posso lançar resultado de semana passada?
**R:** Não diretamente. Solicite ao supervisor, que pode fazer com justificativa.

### P11: Por que o sistema pediu justificativa ao lançar R$ 9.000?
**R:** Porque o valor é mais de 200% da sua meta diária. Isso é uma proteção contra erros de digitação. Basta justificar e confirmar.

### P12: Como anexo mais de um comprovante?
**R:** Clique em **Anexar comprovante** novamente após anexar o primeiro. Você pode anexar até 5 arquivos por resultado.

### P13: Posso deletar um comprovante que anexei errado?
**R:** Sim. Antes de salvar, clique no **X** no canto do arquivo. Depois de salvo, só o supervisor pode remover.

### P14: O áudio que gravei ficou ruim, posso refazer?
**R:** Sim. Antes de salvar, clique em **Apagar áudio** e grave novamente. Depois de salvo, só regravando com um novo resultado.

## Metas e ranking

### P15: Por que não consigo ver o ranking de outra filial?
**R:** Cada filial tem seu próprio ranking. Se você precisar ver outra filial, converse com seu gerente — ele pode configurar permissão.

### P16: Como é calculado o percentual da meta?
**R:** É o resultado dividido pela meta, multiplicado por 100. Ex: R$1.500 / R$3.000 × 100 = 50%.

### P17: O ranking não está atualizando. O que faço?
**R:** 1) Atualize a página (F5). 2) Verifique sua internet. 3) Aguarde 15 minutos (atualização automática). 4) Se persistir, contate o suporte.

### P18: Empatei com um colega no ranking. Como é o desempate?
**R:** O desempate segue critérios configurados pela empresa: geralmente maior faturamento, depois maior ticket médio, depois maior número de clientes.

### P19: Minha meta parece estar errada. Como ajusto?
**R:** Metas são definidas pelo seu gerente. Converse com ele para conferir.

### P20: Posso ver meu ranking histórico de meses anteriores?
**R:** Sim. Em **Ranking**, selecione o período (mês anterior, ano anterior, etc.).

## Campanhas

### P21: Por que não estou em uma campanha que outros colegas estão?
**R:** Algumas campanhas têm critérios específicos (ex: apenas vendedores com mais de 6 meses, ou apenas determinadas filiais). Verifique os critérios com seu gerente.

### P22: Como faço para participar de uma campanha?
**R:** A maioria é automática (você participa ao lançar resultados). Algumas exigem aceite explícito: vá em **Campanhas > Disponíveis > Participar**.

### P23: Ganhei uma medalha mas não recebi o brinde físico. Como recebo?
**R:** Medalhas virtuais são automáticas. Brindes físicos são entregues pela empresa em até 30 dias. Se não receber, contate seu gerente.

### P24: Posso ver minhas medalhas antigas?
**R:** Sim! Acesse **Perfil > Conquistas**. Lá ficam todas suas medalhas e troféus.

## Notificações

### P25: Não estou recebendo notificações push. O que faço?
**R:** 1) Verifique se允许 notificações no navegador/dispositivo. 2) Confirme em **Perfil > Notificações** que push está ativo. 3) Reinstale o PWA se necessário.

### P26: Como paro de receber notificações de certos tipos?
**R:** Em **Perfil > Preferências > Notificações**, desmarque os tipos que não quer receber.

### P27: Recebo notificação às 22h atrapalhando meu sono. Tem como configurar horário?
**R:** Sim! Use o "Não Perturbe" em **Perfil > Preferências > Não Perturbe**.

## IA Coach

### P28: A IA tem acesso aos meus dados pessoais?
**R:** Não. A IA recebe apenas dados comerciais agregados (faturamento, metas). Seus dados pessoais (CPF, e-mail) nunca são enviados.

### P29: A IA tomou uma decisão errada. O que faço?
**R:** A IA nunca toma decisões sozinha. Ela apenas sugere. Se você aceitou uma sugestão errada, você pode desfazer a ação (depende da ação específica).

### P30: A IA está lenta. O que faço?
**R:** A IA pode demorar 5-30 segundos para responder perguntas complexas. Se demorar mais de 1 minuto, cancele e tente novamente. Se persistir, contate o suporte.

### P31: A IA pode ser usada para me avaliar negativamente?
**R:** A IA é uma ferramenta de auxílio. Ela não substitui a avaliação humana do seu gestor. Insights são sugestões para você melhorar, não punições.

### P32: Quanto custa usar a IA?
**R:** Para você, nada. A empresa paga pelo serviço. Mas há um limite mensal configurado pela empresa — se atingir, a IA fica indisponível até o próximo mês.

## Celular e offline

### P33: Posso usar no celular?
**R:** Sim! Instale como aplicativo (Capítulo 11). Funciona offline também.

### P34: O app não instala no iPhone. O que faço?
**R:** Use o Safari (não Chrome). Atualize o iOS para 16.4+. Siga os passos do Capítulo 11.

### P35: Lancei resultado offline mas não sincronizou. O que faço?
**R:** 1) Verifique se voltou a conexão. 2) Abra o app e deixe em primeiro plano por 1 minuto. 3) Se não sincronizar, vá em **Perfil > Sincronizar agora**. 4) Se ainda não, desinstale e reinstale o PWA (dados sincronizados não se perdem).

### P36: O app pesa muito no celular?
**R:** Não. O Orion PWA ocupa em média 15-30 MB, muito menos que apps tradicionais (200+ MB).

## Sistema e desempenho

### P37: O sistema está lento, o que faço?
**R:** 1) Verifique sua internet. 2) Limpe o cache do navegador. 3) Tente outro navegador. 4) Se persistir, contate o suporte.

### P38: A tela está desconfigurada/quebrada. O que faço?
**R:** Atualize o navegador para a versão mais recente. Tente outro navegador. Se persistir, contate o suporte.

### P39: Posso exportar meus dados?
**R:** Sim. Em Histórico > Exportar, você baixa seus dados em PDF ou Excel. Para exportação completa (LGPD), contate o administrador.

### P40: Como vejo qual versão do Orion estou usando?
**R:** Em **Perfil > Sobre** você vê a versão atual, data de build e componentes.

## Outros

### P41: Como mudo o idioma?
**R:** Em **Perfil > Preferências > Idioma**. Disponibilidade depende da licença da empresa.

### P42: Como mudo o tema para escuro?
**R:** Em **Perfil > Preferências > Tema**. Escolha: Claro, Escuro ou Seguir Sistema.

### P43: Posso usar o Orion sem férias/remunerado?
**R:** Se você estiver de férias, seu gerente pode pausar suas metas temporariamente. Você continua conseguindo acessar o sistema, mas sem novas metas.

### P44: Vou sair da empresa. Meus dados ficam?
**R:** Seu acesso é bloqueado. Seus dados históricos são preservados pela empresa por 2 anos para fins de auditoria. Após 2 anos, dados pessoais são anonimizados (LGPD).

### P45: Como reporto um bug?
**R:** Use **Ajuda > Reportar Bug** dentro do sistema, ou contate o suporte. Informe: o que estava fazendo, mensagem de erro, data/hora, dispositivo, navegador.

# Capítulo 16 — Glossário Expandido

## A-C

- **Dashboard:** Tela inicial com resumo dos seus indicadores
- **Indicador:** Métrica que você acompanha (ex: Faturamento, Clientes)
- **Meta:** Valor que você precisa atingir em um período
- **Resultado:** Valor que você efetivamente alcançou
- **Ranking:** Classificação dos vendedores por desempenho
- **Campanha:** Competição temporária com premiação
- **TKM (Ticket Médio):** Valor médio por venda (Faturamento ÷ Nº Clientes)
- **Conversão:** Percentual de visitantes que compraram
- **Atingimento:** Percentual da meta alcançado (Resultado ÷ Meta × 100)
- **Aprovação:** Confirmação do supervisor para que resultado entre oficialmente
- **Anonimização:** Remoção de identificação pessoal de dados (LGPD)
- **Auditoria:** Registro de quem fez o quê e quando no sistema
- **Backup:** Cópia de segurança dos dados
- **Browser:** Navegador (Chrome, Edge, Safari, Firefox)

## D-F

- **Desafio:** Tipo de campanha onde você precisa superar um recorde
- **Dashboard Widget:** Bloco de informação em um dashboard (card, gráfico, tabela)
- **Exportação:** Geração de arquivo (PDF, Excel, CSV) com seus dados
- **Fórmula:** Expressão matemática que calcula um indicador a partir de outros
- **Filial:** Unidade física da empresa (loja, escritório)

## G-I

- **Gamificação:** Uso de elementos de jogos (pontos, medalhas, níveis) para engajar
- **IA Coach:** Inteligência artificial do Orion que sugere melhorias
- **Insight:** Observação inteligente gerada pela IA
- **Indicador primário:** Principal métrica do ranking
- **Indicador derivado:** Calculado a partir de outros (ex: TKM = Faturamento ÷ Clientes)
- **Importação:** Carregar dados em massa (ex: usuários via Excel)
- **Inbox de aprovações:** Lista de resultados pendentes esperando aprovação

## J-L

- **Justificativa:** Texto explicativo exigido em lançamentos atípicos (ex: 200%+ da meta)
- **JWT:** Token de autenticação (JSON Web Token) — usado para manter você logado
- **LGPD:** Lei Geral de Proteção de Dados (Lei 13.709/2018)

## M-O

- **Medalha:** Premiação virtual (Ouro, Prata, Bronze)
- **Multi-tenant:** Sistema que atende múltiplas empresas com isolamento de dados
- **Meta diária:** Meta a ser atingida em um dia
- **Meta mensal:** Meta a ser atingida em um mês
- **Modo offline:** Funcionamento sem internet (resultados ficam pendentes e sincronizam depois)
- **NPS:** Net Promoter Score — métrica de satisfação de clientes
- **Notificação push:** Aviso que aparece no celular mesmo com app fechado

## P-R

- **PWA:** Progressive Web App — aplicativo web instalável no celular
- **Perfil:** Seus dados pessoais e configurações
- **Premiação:** Recompensa por desempenho (medalha, brinde, dinheiro)
- **Pontuação:** Sistema de pontos acumuláveis (gamificação)
- **Permissão:** Direito de executar uma ação (RBAC)
- **RBAC:** Role Based Access Control — permissões baseadas em cargo
- **Reset de senha:** Redefinição de senha (esqueci minha senha)
- **Ranking ponderado:** Ranking que considera pesos diferentes por indicador

## S-U

- **Sessão:** Período em que você está logado
- **Soft delete:** Exclusão que mantém dados preservados (recuperáveis)
- **Sincronização:** Envio de dados offline para o servidor quando volta internet
- **Status:** Estado atual de algo (ex: resultado "Pendente", "Aprovado", "Rejeitado")
- **Supervisor:** Cargo que aprova resultados e gerencia equipe
- **TKM:** Ticket Médio (ver acima)
- **Troféu:** Premiação virtual especial
- **2FA:** Autenticação em dois fatores (senha + código)
- **Tenant:** Empresa cliente no sistema multi-tenant

## V-Z

- **Vendedor:** Usuário final que lança resultados
- **Versão:** Número da release do software (ex: 1.2.3)
- **Webhook:** Notificação automática para sistemas externos
- **Widget:** Bloco de informação no dashboard
- **Whitelist:** Lista de permissões (ex: IPs autorizados)

# Capítulo 18 — Troubleshooting

## 18.1 Não consigo fazer login

### Esqueci a senha
1. Clique em **Esqueci minha senha**
2. Informe seu e-mail/matrícula
3. Verifique o e-mail (inclusive spam)
4. Clique no link (válido por 1 hora)
5. Cadastre nova senha

### Conta bloqueada
- Após 5 tentativas inválidas: bloqueio de 15 minutos
- Aguarde ou peça ao supervisor para desbloquear

### 2FA não funciona
- Verifique se o código está correto (expira a cada 30s)
- Sincronize o horário do celular
- Use um código de backup se disponível
- Contate o admin para redefinir 2FA (comprovação necessária)

### Outros
- Verifique se o e-mail está correto (sem espaços)
- Tente outro navegador
- Limpe cache e cookies
- Verifique sua internet

## 18.2 Resultado não aparece no ranking

### Causa 1: Ainda pendente de aprovação
- Verifique em **Histórico > Resultados Recentes**
- Se status for "Pendente", aguarde o supervisor aprovar

### Causa 2: Recém-lançado
- O ranking atualiza a cada 15 minutos
- Aguarde ou atualize a página (F5)

### Causa 3: Indicador não está no ranking
- Verifique com o gerente se o indicador está configurado para o ranking

### Causa 4: Foi rejeitado
- Você deve ter recebido notificação
- Verifique em **Notificações**
- Lance novamente com correção

## 18.3 Sistema lento

### Verificações
1. **Internet:** teste com outro site (ex: google.com)
2. **Cache:** limpe o cache do navegador
3. **Navegador:** tente outro (recomendado: Chrome)
4. **Dispositivo:** reinicie o computador/celular
5. **Outras abas:** feche abas desnecessárias
6. **Extensões:** desative extensões (especialmente ad-blockers)
7. **VPN:** se usando VPN, tente sem ela

### Se persistir
- Contate o suporte
- Informe: horário, navegador, dispositivo, internet (4G/WiFi)

## 18.4 Não recebo notificações

### Push no navegador
1. Verifique permissões: ícone de cadeado na barra de endereço
2. Habilite notificações
3. Reinicie o navegador

### Push no celular
1. Verifique permissões do app nas configurações do sistema
2. Desative economia de bateria (pode bloquear push)
3. Reinstale o PWA
4. Verifique se há atualizações do sistema operacional

### E-mail
1. Verifique spam/lixo
2. Adicione o remetente aos contatos
3. Verifique se o e-mail está correto em **Perfil**
4. Peça ao admin verificar SMTP

### WhatsApp (se habilitado)
1. Verifique se o número está correto em **Perfil**
2. Verifique se você não bloqueou o número do Orion
3. Confirme com o admin se o plugin está ativo

## 18.5 App não instala

### Chrome (Android)
- Atualize o Chrome
- Verifique se há espaço no celular (mínimo 50MB)
- Limpe cache do Chrome
- Tente desinstalar e reinstalar o Chrome

### Safari (iPhone)
- Atualize o iOS (mínimo 16.4)
- Use o Safari, não Chrome
- Verifique as restrições em Ajustes > Screen Time

### Edge (desktop)
- Atualize o Edge
- Verifique permissões de instalação de PWA

## 18.6 Sincronização offline não funciona

### Verificações
1. Verifique se voltou a conexão
2. Abra o app e deixe em primeiro plano
3. Vá em **Perfil > Sincronizar agora**
4. Se houver erro, você verá a mensagem
5. Tente excluir o resultado pendente e lançar novamente online

### Se persistir
- Faça login novamente (pode ser problema de token expirado)
- Reinstale o PWA
- Contate o suporte

## 18.7 IA não responde

### Causa 1: Limite atingido
- Verifique em **IA Coach > Consumo**
- Se atingiu limite mensal, aguarde renovação

### Causa 2: IA indisponível
- Verifique status em **Ajuda > Status do Sistema**
- Tente novamente em alguns minutos

### Causa 3: Consentimento revogado
- Verifique em **Perfil > Privacidade > Consentimentos**
- Reative se quiser usar

### Causa 4: Pergunta muito complexa
- Reformule de forma mais simples
- Divida em perguntas menores

## 18.8 Resultado sumiu

### Verificações
1. Vá em **Histórico > Todos os Resultados**
2. Filtre por data
3. Verifique o status
4. Se foi rejeitado, houve notificação
5. Se foi excluído, apenas admin pode fazer (auditoria registra)

## 18.9 Erro "Sessão expirada"

### Causa
- Você ficou muito tempo sem atividade (mais de 8h)
- O sistema encerra sessão por segurança

### Solução
1. Faça login novamente
2. Seus dados não foram perdidos
3. Para evitar: salve resultados antes de pausar

## 18.10 Não consigo anexar comprovante

### Causa 1: Tamanho do arquivo
- Máximo: 5 MB por arquivo
- Comprima a imagem (no celular, há apps para isso)

### Causa 2: Formato não suportado
- Aceitos: JPG, PNG, PDF
- Converta se necessário

### Causa 3: Sem permissão de câmera/armazenamento
- Verifique permissões do navegador/app
- No celular, ajuste em configurações do app

### Causa 4: Sem espaço
- Verifique espaço no dispositivo
- Limpe arquivos desnecessários

# Capítulo 21 — Modo Offline

## 21.1 O que funciona offline

Quando você está sem internet, no Orion você pode:

- ✅ Abrir o app
- ✅ Ver dados do último acesso (cache local)
- ✅ Lançar novos resultados (ficam pendentes)
- ✅ Editar resultados ainda não sincronizados
- ✅ Ver suas metas (versão em cache)
- ✅ Ver histórico recente

## 21.2 O que NÃO funciona offline

- ❌ Ver atualizações de ranking
- ❌ Receber novas notificações
- ❌ Aprovar resultados (se for supervisor)
- ❌ Usar IA Coach
- ❌ Exportar relatórios (precisa do servidor)
- ❌ Ver resultados de outros vendedores (além do cache)

## 21.3 Como o Orion sabe que está offline

Aparecerá um ícone no topo:

```
┌────────────────────────────────────┐
│ ⚠️ Você está offline. Dados podem │
│ não estar atualizados.            │
└────────────────────────────────────┘
```

## 21.4 Sincronização automática

Quando voltar a internet:

1. O app detecta a conexão
2. Envia resultados pendentes automaticamente
3. Você vê uma notificação: "3 resultados sincronizados ✓"
4. O ranking é atualizado

## 21.5 Sincronização manual

Se não sincronizar automaticamente:

1. Vá em **Perfil > Sincronizar Agora**
2. Veja a lista de pendentes
3. Toque em **Sincronizar Tudo**
4. Aguarde a confirmação

## 21.6 Conflitos de sincronização

Se você lançar offline mas outra pessoa já tinha lançado algo que afeta seus dados:

- O sistema prioriza a versão online (servidor)
- Sua versão offline é descartada
- Você é notificado do conflito
- Pode refazer se necessário

## 21.7 Dicas para uso offline

- **Lance cedo:** não deixe para lançar só no fim do dia (pode ficar sem internet)
- **Anote valores:** se o app falhar, você ainda tem os valores anotados
- **Verifique status:** antes de confiar em um ranking, verifique se está online
- **Evite editar offline:** se possível, prefira lançar novo a editar

## 21.8 Limpeza de cache offline

Se o app estiver pesado ou lento:

1. Vá em **Perfil > Armazenamento**
2. Veja quanto espaço está sendo usado
3. Toque em **Limpar Cache**
4. Confirme
5. Os dados serão rebaixados quando voltar a internet

> **Cuidado:** Não limpe o cache se tiver resultados pendentes — eles serão perdidos.

## 21.9 Cenários offline comuns

### No transporte
- Lance resultados do dia no ônibus/metro
- Sincroniza ao chegar em casa com WiFi

### Em visita a cliente
- Anote resultados em campo
- Sincroniza ao retornar à empresa

### Internet instável
- Continue trabalhando
- O app detecta conexão automaticamente
- Sincroniza quando possível

### Falha total de internet
- Continue lançando offline
- Quando a internet voltar, tudo sincroniza

- "Como posso aumentar meu ticket médio?"
- "O que fazer para melhorar minha conversão?"
- "Quais produtos devo priorizar?"

### Comparativos
- "Como estou comparado à média da equipe?"

## 23.5 Exemplo de interação

**Você:** "Como posso melhorar meu ticket médio?"

**IA:** "Analisando seus últimos 30 dias, identifiquei que seu ticket médio atual é R$104, abaixo da meta de R$120. Padrões que observei:

1. Você tem maior TKM às terças e quartas (R$115 em média)
2. Às sextas, seu TKM cai para R$92 (provável venda de produtos mais baratos)
3. Seus colegas com maior TKM focam em vendas casadas de perfumes

Sugestões:
1. Reserve 10 minutos às sextas para oferecer produtos complementares
2. Treine vendas casadas (perfume + hidratante)
3. Defina meta pessoal de R$110 para esta semana

Confiança: 87% | Base: 90 dias de dados

[Aceitar e definir lembrete às sextas] [Ver análise completa] [Recusar]"

## 23.6 Insights automáticos

Diariamente às 8h, a IA gera 3-5 insights:

- **Positivos:** "Seu TKM subiu 12% esta semana"
- **Alertas:** "Você está abaixo do ritmo para bater a meta"
- **Oportunidades:** "Você tem chance de subir 2 posições"
- **Padrões:** "Você vende mais às terças — concentre esforços"

Cada insight tem:

- Confiança (50-99%)
- Base (quantos dias de dados)
- Ação sugerida (com botão para aceitar)

## 23.7 Limites de uso

Cada empresa tem um limite mensal de queries:

- Você vê seu consumo em **IA Coach > Consumo**
- Ex: "45 / 100 queries usadas"
- Alertas em 50%, 80%, 100%
- Ao atingir 100%, a IA fica indisponível até o próximo mês

> **Dica:** Se o limite estiver acabando, priorize perguntas importantes. Evite perguntas repetitivas.

## 23.8 Privacidade

- A IA **não recebe dados pessoais** (CPF, e-mail, telefone)
- Recebe apenas dados comerciais agregados (faturamento, metas)
- Conversas com a IA **não são compartilhadas** com seu gestor
- Insights aceitos ficam no seu perfil (você pode apagar)

## 23.9 Revogar consentimento

Se não quiser mais usar a IA:

1. **Perfil > Privacidade > Consentimentos**
2. Desative "Permitir uso de IA em meus dados"
3. A IA Coach fica indisponível
4. Insights automáticos são desativados
5. Histórico de perguntas é apagado

Você pode reativar quando quiser.

## 23.10 Quando a IA erra

A IA pode cometer erros. Se uma resposta parecer errada:

1. **Não confie cegamente** — valide com seus dados
2. **Reformule a pergunta** — às vezes o problema é a pergunta
3. **Verifique o intervalo de dados** — pode estar desatualizado
4. **Reporte** se o erro for grave — use **Ajuda > Reportar Bug IA**

## 23.11 Dicas para perguntas melhores

### Seja específico
- ❌ "Como estou?"
- ✅ "Como está meu faturamento esta semana comparado à anterior?"

### Use período
- ❌ "Como melhoro?"
- ✅ "Como melhoro meu TKM nos próximos 7 dias?"

### Una dois conceitos
- ✅ "Quais produtos devo focar para subir no ranking de perfumes?"

### Peça comparação
- ✅ "Compare meu desempenho com a média da equipe"

### Peça projeção
- ✅ "Se mantiver o ritmo atual, qual minha projeção para o fim do mês?"

## 23.12 Limitações da IA

A IA **não** faz:

- ❌ Toma decisões automáticas
- ❌ Altera metas ou resultados
- ❌ Vê dados de outros vendedores (sem sua permissão)
- ❌ Acessa dados pessoais seus
- ❌ Substitui a avaliação do seu gestor
- ❌ Garante 100% de precisão

A IA é uma **ferramenta de apoio**, não substitui seu julgamento.

# Capítulo 24 — Acessibilidade e Configurações Visuais

## 24.1 Tema claro e escuro

- **Claro:** ideal para ambientes bem iluminados
- **Escuro:** ideal para ambientes escuros, economiza bateria (OLED)
- **Seguir Sistema:** muda automaticamente conforme o sistema operacional

Configure em **Perfil > Preferências > Tema**.

## 24.2 Tamanho de fonte

Em **Perfil > Preferências > Acessibilidade**:

- Fonte pequena (padrão)
- Fonte média
- Fonte grande
- Fonte extra grande

Recomendado para usuários com dificuldade visual.

## 24.3 Alto contraste

Ative para:

- Maior distinção entre elementos
- Cores mais vibrantes
- Útil para ambientes com claridade intensa

## 24.4 Modo daltônico

O Orion tem modo para daltônicos:

- **Deuteranopia** (verde-vermelho)
- **Protanopia** (vermelho-verde)
- **Tritanopia** (azul-amarelo)

Ajusta as cores dos indicadores para serem distinguíveis.

## 24.5 Navegação por teclado

Todo o Orion é navegável por teclado:

- `Tab` para avançar
- `Shift + Tab` para retroceder
- `Enter` para ativar
- `Esc` para fechar
- `Space` para selecionar

Útil para usuários que não usam mouse.

## 24.6 Leitores de tela

O Orion é compatível com:

- NVDA (Windows)
- JAWS (Windows)
- VoiceOver (macOS, iOS)
- TalkBack (Android)

Todos os elementos têm descrições para leitores de tela.

## 24.7 Redução de movimento

Se você tem sensibilidade a animações:

- **Perfil > Preferências > Acessibilidade > Reduzir Movimento**
- Desativa animações de transição
- Mantém apenas o essencial

## 24.8 Velocidade de reprodução de áudio

- Velocidade 1x (padrão)

- Velocidade 2x
